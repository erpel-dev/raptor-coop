This release brings the latest skynettx/raptor changes into the local co-op fork and fixes input, shared weapons, health pickups, and mission completion.

- Restore mouse firing and mixed keyboard/gamepad input, including keyboard fallback after controller disconnect.
- Fix co-op replay state, P2 special-weapon cycling, and regeneration for both living players.
- Make enemy lasers hit the closest living ship and overlapping health pickups heal the most injured eligible player.
- Apply shared weapon loss consistently after low-shield damage and avoid warnings from destroyed teammates.
- Fly all surviving ships offscreen at mission completion.
- Add automated Linux co-op regression tests with setup enabled and disabled, plus Windows and macOS build checks.

Download the archive matching your operating system and architecture, extract it, and follow START-HERE.txt. Linux requires SDL2 and ALSA runtime packages. macOS binaries are ad-hoc signed, not notarized. Original game GLB assets are not bundled; see README.md for installation and co-op controls.

SHA256SUMS contains the checksums for all binary archives. GitHub's source archives contain the corresponding source code. Android and Flatpak builds remain available through the repository's existing manual build instructions.
